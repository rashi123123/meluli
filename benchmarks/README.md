# Benchmark evidence

See [method and limitations](../docs/BENCHMARKS.md). Public FLEURS references/derived-fixture provenance are CC BY 4.0; app benchmark scripts are MIT. Audio and model weights are excluded. Results retain raw hypotheses, settings and measurements, with personal filesystem paths removed. Scores are observations on the documented host, not product accuracy guarantees.

`python3 benchmarks/score.py` recomputes WER/CER from the preserved results and references. It does not download or run any model. `summary.json` records the aggregate 44-clip selection gate used on 24 October 2026.
